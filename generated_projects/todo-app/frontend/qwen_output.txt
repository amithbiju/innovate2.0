**Features Implemented:**
- Task CRUD operations via REST API (`/api/tasks`)
- Material UI components with custom theme
- Date picker for due dates
- Category dropdown (Work, Personal, Shopping, Health, Other)
- Status toggle (Open/Completed)
- Sort by due date (ascending/descending)
- Filter by status (All/Open/Completed)
- Drag-and-drop reordering using dnd-kit
- Loading states and error handling

**To run the app:**
```bash
npm run dev
```

**Note:** The app expects a backend API at `http://localhost:3001/api/tasks`. You'll need to implement the backend endpoints or update the `API_BASE_URL` in `src/services/api.js`.
